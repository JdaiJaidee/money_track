# โปรแกรมบันทึกรายรับ-รายจ่ายส่วนตัว

โปรแกรม CLI ภาษา Python สำหรับบันทึกและสรุปรายรับ-รายจ่ายส่วนตัว เก็บข้อมูลไว้ใน memory (list ของ dict) ระหว่างที่โปรแกรมทำงาน

## วิธีรัน

```
python3 money_tracker.py
```

## ความรู้/แนวคิดที่ใช้

- **List และ dict**: ข้อมูลแต่ละรายการเก็บเป็น `dict` (`date`, `detail`, `category`, `type`, `amount`) แล้วเก็บรวมกันใน `list` ชื่อ `transactions`
- **Function-based structure**: แยกงานแต่ละส่วนเป็นฟังก์ชันเดี่ยว ๆ (ไม่ใช้ class) รับ `transactions` เป็นพารามิเตอร์แล้วแก้ไข list เดิม (mutate in place) แทนการ copy ใหม่ทุกครั้ง
- **Loop จน valid (`while True` + `continue`)**: ใช้กับ input ที่ต้อง validate เช่นวันที่และจำนวนเงิน ถ้าใส่ผิดจะวนถามใหม่ ไม่ปล่อยผ่านค่าที่ผิด
- **`datetime.date()`**: ใช้เช็กว่าวันที่ที่กรอกมีอยู่จริงในปฏิทิน (เช่น 30 ก.ย. มีจริง แต่ 31 ก.ย. ไม่มี, รองรับปีอธิกสุรทัน) แล้วใช้ `strftime("%Y-%m-%d")` เติมเลข 0 นำหน้าให้อัตโนมัติเวลาเก็บ
- **String formatting (`f-string`)**: จัดคอลัมน์ตาราง (`<`, `>`, ความกว้างคงที่) และจัดรูปแบบตัวเลขทศนิยม/คั่นหลักพัน (`:,.2f`)
- **`sorted()` + `key`**: เรียงรายการตามวันที่จริง (แปลงเป็นเลขก่อนเรียงกันปัญหาเลขไม่เติม 0), เรียงหมวดหมู่ตามยอดรวมจากมากไปน้อย
- **List comprehension**: กรองรายการ เช่น กรองตามเดือน (`t["date"].startswith(month)`) หรือกรองตามประเภท (รายรับ/รายจ่าย)
- **Dict เป็นตัวรวมยอด (`category_totals.get(...)`)**: ใช้หมวดหมู่เป็น key สะสมยอดรายจ่ายแต่ละหมวด
- **Identity-safe update/delete (`list.remove`, `list.index`)**: เมนูลบ/แก้ไขแสดงรายการที่ *เรียงแล้ว* แต่ยังต้องลบ/แก้ไข object เดิมใน list จริงให้ถูกตัว จึงจับคู่กลับด้วย object เดียวกัน ไม่ใช้เลขลำดับที่แสดงตรง ๆ
- **`assert`-based self-test (`_selftest()`)**: เทสต์ logic ที่เป็นตัวเลข/การกรอง (`calculate_summary`, `calculate_category_summary`, กรองตามเดือน) อัตโนมัติทุกครั้งที่รันโปรแกรม ก่อนเข้า `main()`

## เมนูทั้งหมด

| เลข | เมนู | ทำอะไร |
|----|------|--------|
| 1 | เพิ่มรายการ | ถามวันที่/รายละเอียด/หมวดหมู่/ประเภท/จำนวนเงิน แล้วเพิ่มเข้า `transactions` |
| 2 | แสดงรายการทั้งหมด | แสดงตารางทุกรายการ (เรียงตามวันที่) พร้อมยอดรวมรายรับ/รายจ่าย/คงเหลือ |
| 3 | สรุปยอดเงิน | สรุปยอดรวมรายรับ/รายจ่าย/คงเหลือทั้งหมด (ไม่แสดงรายการย่อย) |
| 4 | ลบรายการ | แสดงรายการ (เรียงตามวันที่) ให้เลือกหมายเลขเพื่อลบ, กด 0 ย้อนกลับ |
| 5 | แก้ไขรายการ | แสดงรายการ ให้เลือกหมายเลขแล้วกรอกข้อมูลใหม่แทนของเดิมทั้งหมด, กด 0 ย้อนกลับ |
| 6 | สรุปรายเดือน | กรอกเดือน (ปปปป-ดด) แล้วเลือกดูสรุปรวม/เฉพาะรายรับ/เฉพาะรายจ่ายของเดือนนั้น, กด 0 ย้อนกลับ |
| 7 | สรุปตามหมวดหมู่ | รวมยอดรายจ่ายแยกตามหมวดหมู่ เรียงจากมากไปน้อย |
| 8 | กราฟแท่งตามหมวดหมู่ | เหมือนเมนู 7 แต่แสดงเป็นแท่งกราฟตามสัดส่วน พร้อม % ของยอดรายจ่ายรวม |
| 9 | Top 3 หมวดใช้จ่าย | เหมือนเมนู 7 แต่โชว์แค่ 3 อันดับแรก |
| 10 | ออกจากโปรแกรม | จบการทำงาน |

## สรุปการทำงานของแต่ละฟังก์ชัน

- **`show_menu()`** — พิมพ์รายการเมนูทั้งหมด
- **`ask_date()`** — วนถาม input วันที่รูปแบบ `ปปปป-ดด-วว` จนกว่าจะเป็นตัวเลขครบ 3 ส่วนและเป็นวันที่จริงตามปฏิทิน (เช็กผ่าน `datetime.date`) คืนค่าวันที่แบบเติม 0 นำหน้าแล้ว
- **`ask_type()`** — ถามเลือกประเภท 1 (รายรับ) หรือ 2 (รายจ่าย) คืนค่าข้อความไทย หรือ `None` ถ้าเลือกผิด
- **`ask_amount()`** — วนถามจำนวนเงินจนกว่าจะเป็นตัวเลขและมากกว่า 0 ถ้าผิดจะแจ้งเตือนแล้วให้กรอกใหม่ (ไม่ยอมปล่อยผ่าน)
- **`ask_category()`** — ถามหมวดหมู่ (ข้อความอิสระ เช่น อาหาร, เดินทาง)
- **`get_sorted_transactions(transactions)`** — คืน list ใหม่ที่เรียงตามวันที่จริง (แปลงวันที่เป็นตัวเลขก่อนเปรียบเทียบ กันปัญหาวันที่ไม่เติม 0)
- **`print_transaction_list(transactions)`** — พิมพ์รายการแบบเรียบ ๆ ทีละบรรทัด (ใช้ในเมนูลบ/แก้ไข/สรุปรายเดือน)
- **`calculate_summary(transactions)`** — วนรวมยอดรายรับ/รายจ่ายทั้งหมด คืนค่า `(income, expense, balance)`
- **`calculate_category_summary(transactions)`** — รวมยอด "รายจ่าย" แยกตามหมวดหมู่ด้วย dict แล้วเรียงจากมากไปน้อย คืนเป็น list ของ `(หมวดหมู่, ยอดรวม)`
- **`add_transaction(transactions)`** — เก็บ input ทั้งหมด (วันที่/รายละเอียด/หมวดหมู่/ประเภท/จำนวนเงิน) ประกอบเป็น dict แล้ว append เข้า list
- **`show_all_transactions(transactions)`** — พิมพ์ตารางรายการทั้งหมด (เรียงตามวันที่) พร้อมสรุปยอดท้ายตาราง
- **`show_summary(transactions)`** — พิมพ์สรุปยอดรวมอย่างเดียว ไม่แสดงรายการย่อย
- **`show_monthly_summary(transactions)`** — กรองรายการเฉพาะเดือนที่ระบุ, มีเมนูย่อยให้เลือกดูสรุปรวม/รายรับอย่างเดียว/รายจ่ายอย่างเดียว
- **`show_category_summary(transactions)`** — พิมพ์ยอดรายจ่ายแต่ละหมวดหมู่ เรียงจากมากไปน้อย
- **`show_category_chart(transactions)`** — เหมือนข้างบนแต่วาดเป็นแท่งกราฟ (`█`) ตามสัดส่วนเทียบหมวดที่มากที่สุด พร้อมคำนวณ % ของยอดรายจ่ายรวม
- **`show_top_categories(transactions, top_n=3)`** — ตัด `calculate_category_summary()` ให้เหลือแค่ N อันดับแรก (default 3)
- **`ask_valid_index(transactions, question)`** — ถามหมายเลขลำดับ, กด 0 = ยกเลิก/ย้อนกลับ, เช็กว่าเป็นตัวเลขและอยู่ในช่วงที่มีจริงก่อนคืนค่า index (index เริ่มจาก 0)
- **`delete_transaction(transactions)`** — แสดงรายการที่เรียงแล้ว ให้เลือกลบ แล้วใช้ `list.remove()` ลบ object เดิมออกจาก list จริง (กันปัญหาลำดับที่แสดงไม่ตรงกับลำดับใน list ต้นฉบับ)
- **`edit_transaction(transactions)`** — แสดงรายการที่เรียงแล้ว ให้เลือกแก้ แล้วหา index จริงด้วย `list.index()` ก่อนแทนที่ dict เดิมด้วยข้อมูลใหม่ทั้งชุด
- **`main()`** — loop หลัก แสดงเมนู อ่านตัวเลือก แล้วเรียกฟังก์ชันที่ตรงกัน จนกว่าจะเลือกออกจากโปรแกรม
